# RepoRobos

Este repositório é dedicado ao estudo e desenvolvimento de estratégias para robôs de trading, com foco em teoria de price action, day trade, codificação NTFL e análise de dados de abertura e fechamento.

## Objetivos
- Explorar e documentar teorias de price action aplicadas ao day trade.
- Desenvolver e testar robôs utilizando NTFL e Python.
- Analisar dados históricos de mercado para embasar estratégias.
- Compartilhar exemplos, scripts e resultados de experimentos.

## Estrutura Sugerida
- `python/` — Scripts e notebooks para análise de dados e prototipagem de estratégias.
- `teorias/` — teorias de price action, indicadores e tudo que se precisa saber para trade.
- `operacionais/` — Documentação de padrões de operação.
- `backtest/` — Anotação de informações dos ultimos 5 anos de candles para formular teorias.
- `codigos/` — Códigos de robôs e estratégias implementadas.
https://github.com/wesleyzilva/PriceAction_Fisica/tree/main
